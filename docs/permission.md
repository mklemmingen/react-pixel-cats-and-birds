# Sprite permission

The cat and bird sprites by Pop Shop Packs (https://pop-shop-packs.itch.io/) are bundled in this
package with the artist's permission, on the condition that she is credited clearly.

Where she is credited:

- README.md ("Credits" section near the top)
- CREDITS.md (packs, files, terms)
- LICENSE (header separating MIT code from the sprites)
- package.json (`description`, `contributors`)
- llms.txt
- source headers of src/sprites.js, src/Cats.js, src/Birds.js, src/core/catSim.js, src/core/birdSim.js
- playground footer
- GitHub release notes
